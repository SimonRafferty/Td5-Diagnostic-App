Update your Td5 dongle

Latest firmware: checking…

  1. Use Google Chrome or Microsoft Edge on a computer (Windows, Mac or Linux). Phones and tablets can't do this.
  2. Unplug the dongle from the car. Connect it to the computer with a USB-C cable.
  3. Click the green Install button below. A list pops up: pick the dongle (it may be called "USB JTAG/serial debug unit") and click Connect, then Install.
  4. Wait for "Installation complete" (under a minute). Unplug the cable and plug the dongle back into the car. That's it.
This browser can't update the dongle. Please open this page in Google Chrome or Microsoft Edge on a computer.

If it doesn't work

  • Nothing appears in the list? Many USB-C cables only charge - try a different cable, or a different USB socket on the computer.
  • Still nothing? Unplug the dongle, wait a few seconds, plug it back in and click Install straight away.
  • It stopped part-way or showed an error? Just click Install again. It is safe to repeat, and your settings are kept.
  • Still stuck? Report the problem here. Say what happened and, if you can, add a screenshot of any error message. (You'll need a free GitHub account.)
